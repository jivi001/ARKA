## Risks accepted as invariants, not open design options

- No development flag may place a real provider secret or A2A signing key in an untrusted agent process.
- No agent or LLM may authorize, approve, issue credentials, alter scope, or bypass the kernel/broker path.
- No fallback to direct agent networking or a permissive parser is allowed when a control fails.
- A2A signatures authenticate a message only; they do not make its payload true or authorized.
- Regex/token-pattern detection cannot prove credential isolation or complete egress safety.
- A mapped OWASP category is not a complete threat model or an acceptance result.
